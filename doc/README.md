# About Help

`Modbus Tools` `client` and `server` applications ship plain HTML documentation
generated by `doxygen`, opened in the user's default web browser (F1 / Help >
Contents).

Help for `client` and `server` is generated separately from the `doxygen`
project files `DoxyfileClient` and `DoxyfileServer`.

# Build Help Files manually

To create the HTML documentation:
```console
doxygen DoxyfileClient
doxygen DoxyfileServer
```

This produces `client/html/index.html` and `server/html/index.html` (plus
supporting assets) under the doxygen output directory.

* ...
